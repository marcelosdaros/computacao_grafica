## Integralização GB
Cena construída simulando as pirâmides do Egito, implementando todos os conceitos vistos ao longo do semestre (operações geométricas, texturas, iluminação, câmera e movimentação), com a leitura dos objetos via arquivo JSON de configuração. A apresentação de slides e o vídeo entregues na atividade do moodle contém mais detalhes da implementação.
* Como compilar e executar: siga os passos do arquivo **GettingStarted.md**, mas no passo 2 utilize esse comando para clonar o projeto:
```sh
git https://github.com/marcelosdaros/computacao_grafica.git
```
Caso você esteja na branch main, troque para a branch `trabalho_gb`. Se as configurações iniciais já foram feitas, vá para o passo 4 para compilar e executar o programa.
* Comandos:
    * Teclas WASD e mouse: controle e movimentação da câmera
    * Teclas 4, 5 e 6: seleciona a pirâmide para aplicação das operações geométricas descritas abaixo
    * Teclas IJKL: translação da pirâmide selecionada
    * Teclas Z e X: aumenta/diminui a escala da pirâmide selecionada
    * Setas e teclas 1 e 2: faz rotações no objeto selecionado
